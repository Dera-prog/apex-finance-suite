Structure

Fourteen frames, one spine

Grey boxes, real decisions. Each frame shows hierarchy and state logic without the distraction of colour; the numbered notes call out the rules that matter.

Lo-fi legend. Dashed box = region with variable content · solid fill = fixed chrome · numbered chip = annotation. Every money screen shares the same top-to-bottom spine: context → amount → consequence → confirm.
